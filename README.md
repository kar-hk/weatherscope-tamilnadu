**Comprehensive Weather Intelligence Platform for Thoothukudi & Surrounding Regions**

WeatherScope Tamil Nadu is a web application that provides **real-time, location-specific weather information** for coastal Tamil Nadu. It is designed for local residents, fishermen, farmers, port workers, tourists, and students, integrating forecasts, marine conditions, air quality, and alerts—available in both Tamil and English.

## Features

- **Real-time Weather Data:** Temperature, humidity, wind, pressure, UV index, sunrise/sunset, and “feels like” temperature.  
- **7-Day Forecasts:** High/low temperatures, rainfall probability, detailed icons & summaries.  
- **Weather Alerts:** Cyclone warnings, monsoon updates, marine safety advisories.  
- **Marine & Air Quality Monitoring:** Wave height, sea conditions, AQI, PM2.5/PM10 with health advisories.  
- **Hourly Outlook:** Forecasts for the next 24 hours.  
- **Interactive Maps:** Rainfall radar & temperature overlays.  
- **Bilingual Interface:** Tamil & English.  
- **Mobile-friendly Design:** Fully responsive UI for phones, tablets & desktops.  
- **Multi-location Support:** Thoothukudi, Chennai, Tirunelveli, Madurai, Kanyakumari, and Rameswaram.

## Quick Start

### Prerequisites

- Modern browser (Chrome, Firefox, Edge, Safari)  
- Git & Node.js (for development)

### Installation

1. **Clone the Repository**
    ```bash
    git clone https://github.com/kar-hk/weatherscope-tamilnadu.git
    cd weatherscope-tamilnadu
    ```
2. **Install Dependencies**
    ```bash
    npm install
    ```
3. **Run Development Server**
    ```bash
    npm start
    ```
4. **Open `index.html` directly** for a static preview.

### Deploying to GitHub Pages

- Enable GitHub Pages in repository settings and set the source folder to `/src`.  
- Your app will be live at:  
    ```
    https://yourusername.github.io/weatherscope-tamilnadu/
    ```
