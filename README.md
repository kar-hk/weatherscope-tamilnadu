# WeatherScope Tamil Nadu 🌦️

**Comprehensive Weather Intelligence Platform for Thoothukudi and Surrounding Regions**

***

## Overview

**WeatherScope Tamil Nadu** is a specialized web application designed to provide precise and culturally relevant weather information for Thoothukudi (Tuticorin) and neighboring areas in Tamil Nadu, India. Built for local residents, fishermen, port workers, farmers, tourists, and students, it integrates real-time weather data, forecasts, marine conditions, and critical alerts—accessible in both Tamil and English.

## Features

- **Real-time Weather Data**: Current temperature, humidity, wind, pressure, UV index, sunrise/sunset, and \"feels like\" temperature.
- **Multi-location Support**: Thoothukudi, Chennai, Tirunelveli, Madurai, Kanyakumari, and Rameswaram—switch easily between locations.
- **7-Day Forecasts**: With rainfall probability, temperature highs/lows, detailed icons and summaries.
- **Weather Alerts**: Monsoon warnings, cyclone alerts, marine safety, and color-coded severity.
- **Marine Weather**: Wave height, sea conditions, winds—essential for fishermen and port operations.
- **Air Quality Monitoring**: Live AQI, PM2.5, PM10, and health advisories.
- **Hourly Outlook**: Detailed conditions for the next 24 hours.
- **Weather Maps**: Interactive rainfall radar and temperature overlays.
- **Bilingual Interface**: Tamil and English language options for all content.
- **Mobile-friendly Design**: Responsive UI optimized for phones, tablets, and desktop use.

## Quick Start

### Prerequisites

- Modern browser (Chrome, Firefox, Edge, Safari)
- Git & Node.js (for development)

### Installation

1. **Clone the Repository**
    ```bash
    git clone https://github.com/yourusername/weatherscope-tamilnadu.git
    cd weatherscope-tamilnadu
    ```
2. **Install Dependencies** (for local development and build tools)
    ```bash
    npm install
    ```
3. **Run Development Server**
    ```bash
    npm start
    ```
4. **Open `index.html` directly for a static preview.**

### Deploying to GitHub Pages

- Enable GitHub Pages in repo settings, set source to `/src`, and your app will be live at:
    ```
    https://yourusername.github.io/weatherscope-tamilnadu/
    ```
